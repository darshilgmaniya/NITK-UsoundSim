# NITK-UsoundSim — Tissue Interaction + Phantom Module

## A. What is implemented

This version extends the submitted preliminary tissue module without changing
its propagation-facing contract.

1. **Distributed liver-like point scatterers** are generated by `phantom.py`.
2. Scatterer positions are uniformly distributed in a 2-D imaging region.
3. Signed scattering amplitudes are sampled from a reproducible zero-mean
   Gaussian distribution to provide a synthetic speckle-producing field.
4. A configurable elliptical focal lesion changes the local scatterer
   statistics to create hypo-/iso-/hyperechoic behaviour in the acoustic
   domain.
5. Optional lesion impedance can be carried with lesion scatterers.
6. `tissue_interaction.py` converts an incident pressure waveform into a
   scattered waveform using the existing `amp` field, while retaining the
   preliminary impedance-contrast modifier.
7. No TX/RX delay, attenuation, receive beamforming, RF conversion, scan
   conversion, or B-mode processing is performed here.

The supplied preliminary README explicitly defines the current call chain as
`forward_propagation -> mock_tissue_interaction -> return_propagation` and
requires a same-shape 1-D waveform output. The new implementation preserves
that contract.

## B. Files

- `tissue_interaction.py` — drop-in tissue interaction implementation.
- `phantom.py` — deterministic 2-D acoustic phantom and lesion generator.
- `tests/test_tissue_interaction.py` — unit and integration-contract tests.
- `validate_phantom.py` — generates diagnostic plots.
- `validation_plots/` — generated diagnostics.

## C. Existing interfaces preserved

The current submitted propagation contract is:

```python
incident_wave, d_tx, t_tx = forward_propagation(...)
reflected_wave = mock_tissue_interaction(incident_wave, scatterer)
pressure_s, d_rx, t_rx = return_propagation(reflected_wave, ...)
```

The tissue function remains:

```python
mock_tissue_interaction(incident_wave, scatterer) -> reflected_wave
```

where `incident_wave` is a 1-D pressure waveform and `scatterer` contains at
least `x`, `z`, and `amp`. The output has exactly the same shape as the input.

The supplied project material also states that return propagation handles the
scatterer-to-receiver path and that tissue interaction must not add propagation
delays or beamforming.

## D. Interface changes required

**None for the existing propagation call.**

The new phantom generator supplies richer dictionaries, but the propagation
module can consume the minimum legacy fields (`x`, `z`, `amp`) through:

```python
phantom.as_legacy_scatterers()
```

If the propagation implementation ignores extra dictionary fields, the richer
scatterer dictionaries can be passed directly. If it validates an exact set of
keys, use `as_legacy_scatterers()`.

### Important limitation of the available project files

README were available in this task. The actual `Acoustic Propagation` source
file was not supplied. Therefore its exact function signature, array
orientation, sampling frequency, element geometry, and accumulation logic

## E. Equations

### Normal-incidence pressure reflection coefficient

```text
R = (Z2 - Z1) / (Z2 + Z1)
```

`Z` is acoustic impedance in MRayl. The sign is retained. For distributed
point scatterers, `amp` remains the primary local scattering strength rather
than treating every microscopic scatterer as a large planar interface.

### Scattered waveform

For the compatible first-order model:

```text
p_scattered(t) = G_scatterer * p_incident(t)
```

where `G_scatterer` is derived from `amp`, with an optional modest impedance
contrast factor:

```text
G = amp * (1 + |R|) * interaction_scale
```

when both local and background impedance are supplied. Without impedance
fields, `G = amp * interaction_scale`.

### Speckle model

Background amplitudes are sampled as:

```text
a_i ~ Normal(0, sigma_background^2)
```

with a fixed NumPy random seed. This is a synthetic point-scatterer model,
not a claim that human liver microstructure is Gaussian or uniformly
scattered.

## F. Parameter assumptions

| Parameter | Default | Type/status |
|---|---:|---|
| Array element count | not set here | Existing transducer/propagation responsibility |
| Background impedance | 1.63 MRayl | Preserved from submitted preliminary module |
| Phantom lateral extent | -25 to +25 mm | Simulation assumption |
| Phantom depth | 10 to 60 mm | Simulation assumption |
| Scatterer density | 120,000 m^-2 | Simulation assumption |
| Background amplitude std. | 1.0 | Dimensionless simulation parameter |
| Seed | 2026 | Reproducibility setting |
| Lesion shape | ellipse | Simulation assumption |
| Default lesion class | hypoechoic | Simulation setting |
| Default lesion scale | 0.35 | Dimensionless simulation parameter |

These values are not manufacturer specifications unless explicitly stated as
such. In particular, no Philips probe dimensions or acoustic specifications
were invented by this module.

## G. Units

- Position `x`, `z`: metres internally.
- Acoustic impedance: MRayl.
- Waveform: mechanical pressure units inherited from the propagation module.
- Sampling frequency: **not defined by this module**; it must be inherited
  from the existing propagation/TX waveform implementation.
- Time delay: **not defined by this module**.
- Scatterer amplitude: dimensionless relative strength.

## H. How scatterers are generated

`generate_liver_phantom()` uses:

```python
rng = np.random.default_rng(seed)
```

Then it samples `N = density × phantom_area` positions uniformly in the
2-D rectangle and samples a signed Gaussian amplitude for each point. A
scatterer is represented by a dictionary containing `x`, `z`, `amp`, and
metadata such as `is_lesion` and optional impedance.

The propagation module remains responsible for calculating travel times to
and from each scatterer and accumulating the received signals.

## I. Lesion representation

The lesion is an ellipse:

```text
((x-cx)/rx)^2 + ((z-cz)/rz)^2 <= 1
```

Scatterers falling inside the ellipse receive a configurable scattering scale:

- `hypoechoic`: default scale 0.35
- `isoechoic`: scale 1.0
- `hyperechoic`: scale 1.8

A user can override the scale directly. An optional lesion impedance can also
be attached to those scatterers for impedance-contrast experiments.

The lesion therefore exists in the **acoustic phantom**, not in image space.
No B-mode pixel is edited or brightness-adjusted.

## L. Known limitations

1. The scatterer response is linear and frequency-independent.
2. No coherent phase/amplitude scattering model beyond signed point
   amplitudes is included.
3. No frequency-dependent attenuation is implemented here.
4. No nonlinear propagation is implemented here.
5. No specular interface geometry is explicitly modelled; the impedance
   coefficient is retained mainly as an optional local modifier.
6. The synthetic scatterer density is not a histological model of human liver.
7. A realistic B-mode appearance depends strongly on the existing propagation,
   receive beamforming, envelope detection, log compression, and scan
   conversion implementations.
8. The actual Acoustic Propagation source was not included in the supplied
   files, so the complete 128-channel integration cannot be executed or
   claimed as verified here.

## M. Exact handoff specification

### Input from Acoustic Propagation

For each scatterer:

```python
incident_wave: np.ndarray  # shape (n_samples,), mechanical pressure waveform
scatterer: Mapping[str, float]
```

Minimum required scatterer fields:

```python
{
    "x": float,      # metres
    "z": float,      # metres
    "amp": float,    # dimensionless local scattering strength
}
```

Optional fields:

```python
"impedance_mrayl": float
"background_impedance_mrayl": float
"interaction_scale": float
```

### Tissue Interaction output

```python
reflected_wave = mock_tissue_interaction(incident_wave, scatterer)
```

Guarantees:

- 1-D NumPy array.
- Same shape as `incident_wave`.
- Finite values for finite valid inputs.
- No added propagation delay.
- No receive-channel assumptions.
- No beamforming.

### Handoff to Return Propagation

The returned waveform is the source waveform for the existing return
propagation calculation from that scatterer to the receive elements.
The tissue module does not determine which of the 128 elements receive it.
